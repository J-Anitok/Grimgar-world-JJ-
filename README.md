# Grimgar — feature/ui-and-tests

This branch adds a minimal React + Vite app and a no-build demo to exercise the upgraded grimgar.ts logic.

How to run (React app):

1. Install dependencies: npm install
2. Run dev server: npm run dev
3. Open http://localhost:5173

No-build demo:

Open `demo/index.html` in a browser (double-click or serve it from a static server). This demo is standalone and demonstrates a simple NPC list and scavenger roll without any build.
